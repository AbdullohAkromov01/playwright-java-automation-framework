# Playwright Java Automation Framework

UI automation framework built with Playwright, Java, and TestNG using the Page Object Model (POM) design pattern.

## Test Application
https://www.saucedemo.com/

## Tech Stack
- Java 21
- Playwright
- TestNG
- Maven
- Allure Reports

## Features
- Page Object Model (POM)
- Screenshot Capture
- Allure Reporting
- TestNG Integration

## Run Tests

```bash
mvn clean test
allure serve allure-results
